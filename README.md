# 🖼️ Görüntü İşleme App

### Image Processing Application with Python & OpenCV

A desktop application that performs common image processing operations using Python and OpenCV. The project provides an interactive interface for applying filters, transformations, edge detection, thresholding, and other fundamental computer vision techniques.

</div>

---

##  About

This project was developed to explore fundamental **image processing** and **computer vision** techniques through an easy-to-use desktop application.

Users can load images, apply different processing operations, compare results, and better understand how digital image manipulation works using OpenCV.

---

##  Features

*  Load and display images
*  Grayscale conversion
*  RGB channel processing
*  Edge detection
*  Binary thresholding
*  Blur & smoothing filters
*  Image enhancement
*  Resize & transformation
*  Histogram operations
*  Save processed images
